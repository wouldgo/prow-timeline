Cumulative counters in selected test

The last observation before the test is the baseline. In-test rows show the cumulative count per UID and the increase since its previous observation. An increase bounded by two in-test observations occurred within the test window; this does not prove causality. A boundary-crossing increase can include occurrences before the test. Future observations are excluded. Filters apply to both the baseline and progression. So far is the sum of maximum counters per UID observed by the test's end, including earlier history.

How to read this view

Focused mode includes intervals intersecting the selected test, including points exactly at either endpoint. A margin leaves room for start/end lines. Only the visible segment is drawn; full original intervals remain in details. Entire step / run mode retains access to all outside events. Filters apply to events, not test selection. Active tests are all test intervals intersecting an event, not an inference of causality. Pagination bounds event DOM to 60 rows. Test search shows up to 300 choices plus retained matching selections; narrow the search to find more.
